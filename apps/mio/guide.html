MIO の使い方

MIO - 学生生活まるごと管理 ／ 最終更新日：2026年8月18日

MIO（ミオ）は、時間割・出欠・単位・課題・試験・予定・バイト・家計簿・タスク・就活・友達・サークル・イベント・割り勘・日記まで、大学生の毎日をまるごと管理できるアプリです。 入力したデータは基本的にあなたの端末の中に保存され、ネットにつながっていなくても使えます。友達と共有したいときや、機種変更で引き継ぎたいときだけクラウドを使います。 このページでは、各機能の使い方・できること・小技・よくある質問をまとめています。

まず覚えたい基本操作

どの画面でも共通の操作です。ここだけ押さえれば、あとは触りながら覚えられます。

画面の切り替え（下のタブ）

画面のいちばん下に、5つのタブが並んでいます。タップで画面を切り替えられます。

  • ホーム：今日やることの総まとめ。
  • カレンダー：予定・授業・バイト・イベント・誕生日を1枚のカレンダーで。
  • 学校：時間割・授業・課題・試験（上部のボタンで切り替え）。
  • くらし：家計簿・バイト・タスク・就活。
  • 友達：イベント・サークル・割り勘・友達。

📝 タブの分かれ方タブは機能のジャンル分けではなく、「いじった結果が誰に届くか」で分かれています。「くらし」は自分だけのもの、「友達」は誰かに届くもの。だから「くらし」に新着の赤い印は出ません（自分だけのものに新着は無いので）。

設定を開く

どの画面でも、右上の歯車アイコンから設定を開けます。通知・見た目・アカウント・データ管理・お問い合わせはすべてここです。

💡 いちばんの小技いま開いているタブをもう一度タップすると、そのタブの中身が順番に切り替わります。

  • 「学校」を連打 → 時間割 → 授業 → 課題 → 試験 → …と巡回。
  • 「くらし」を連打 → 家計簿 → バイト → タスク → 就活 → …と巡回。
  • 「友達」を連打 → イベント → サークル → 割り勘 → 友達 → …と巡回。
  • 「カレンダー」を連打 → 表示を切り替えつつ、今週・今月に戻る。
  • 「ホーム」を連打 → いちばん上までスクロール。

スワイプ・ジェスチャー

  • 左右スワイプで期間を送れます（カレンダーの日/週/月、バイトや家計簿の月、日記の月など）。
  • 入力用のシート（予定・シフトなどの追加画面）は下にスワイプで閉じられます（書きかけがあれば確認します）。
  • 文字入力中に余白をタップするとキーボードが閉じます。
  • 友達・サークルの一覧やホームは下に引っ張って更新できます（クラウドと同期します）。

学期の切り替え

「学校」タブでは、上部の見出し「◯年度 ◯学期」をタップすると学期を切り替えられます。時間割は選んだ学期のものが表示されます。授業の一覧は、学期を切り替えても全学期ぶんが並びます。

はじめて開いたとき

初回はかんたんな初期設定（オンボーディング）が出ます。順に、アカウント（あとから連携も可能。「アカウントなしではじめる」を選べばすぐ使えます）→ 名前・学校・アイコン → デザインのプリセット → 年度・学期 → 時間割（時限・曜日）→ 通知、の順です。

📝 メモネットにつながっていない場所でも、ほとんどの機能はそのまま使えます。友達への共有やクラウドへの反映は、電波が戻ったときや次に画面を開いたときに自動でやり直されます。

ホーム（と日記）

「今日」に必要なものだけを1画面に集めた場所です。他のタブの内容をぜんぶ読み込んで表示しています。

  • 今日の授業：時限つきで並びます。祝日は「お休み」表示に切り替わります。タップで授業の編集へ。
  • 出欠のクイック記録：授業ごとに 出席 / 遅刻・早退 / 欠席 / 休講 をその場で記録。「今日はまとめて出席」も1タップです。
  • 今日と明日の予定：個人の予定・共有イベント・バイトのシフト・友達の誕生日・就活の予定を、1本の時間順のリストにまとめます。
  • 直近1か月の試験と未提出の課題（最大5件）。
  • タスクカード：未完了の直近5件。チェックで完了、その場で追加・編集もできます。
  • 要回答のイベント：返事待ちの共有イベントを最優先で出します。
  • はじめかたチェックリスト：卒業単位 → 授業 → 時間割 → 学期の期間 → バイト → 設定 → ウィジェット → アプリアイコン の順に初期設定を案内します。
  • 友達の時間割へのリンク、学期が終わったときの切り替え案内。

日記

独立したタブではなく、ホームの日記カードから履歴ページに入ります。

  • 1日1件。気分だけ（本文なし）でも保存できます。気分は5択（😆 🙂 😐 😢 😡）＋好きな絵文字。
  • 月ごとの履歴と件数、月めくり、空の日を隠す切り替え。
  • 過去の空いている日にはあとから書けます。未来の日には書けません。
  • 長押しで編集・削除。

カレンダー

アプリの中のあらゆる日付データを1枚にまとめます。ここだけはバナー広告を出していません（週の表示が崩れるため）。

5つの表示

上部のボタンで リスト / 月間 / 週間 / 3日間 / 日 を切り替えられます。「今日へ戻る」もあります。

まとまって出るのは、個人の予定・共有イベント・課題の期限・試験・就活の予定・バイトのシフト・友達の誕生日、そして（設定で有効にすれば）授業です。

予定の追加・編集・削除

  1. 右下の＋、または日付をタップして追加。
  2. 週間・3日・日の表示では、空いている時間をドラッグすると、掴んだ範囲がそのまま予定の時間になります。
  3. 入れられるのは、タイトル・日時（終日も可）・場所（履歴から候補、地図アプリも開けます）・メモ・色・リマインダー。
  4. 置いたあとも、15分単位のドラッグで移動・伸縮ができます。

繰り返し予定

毎日 / 毎週 / 毎月 / 毎年 / 間隔指定 / 曜日指定 / 第何曜日 / 終了日 から選べます。編集と削除のときは「今回のみ・今回以降・すべて」を選びます。

リマインダー（通知）

1つの予定にいくつでも付けられます（5分前・1時間前・前日など）。

誕生日・祝日

友達の誕生日が自動で並びます（誕生日の友達には王冠がつきます）。タップするとプロフィールを見たり、誕生会のイベントを作れます。日本の祝日はアプリに同梱していて、「祝日は授業なし」として扱う設定もあります。

学校（時間割・授業・課題・試験・単位）

上部のボタンで 時間割 / 授業 / 課題 / 試験 を切り替えます。すべて年度 × 学期で管理します。

時間割

  • 空きコマをタップして授業を新規作成。すでに作った未配置の授業を置くこともできます。
  • 時限の数、各時限の開始・終了時刻、土日を出すかどうか、学期の期間を設定できます。
  • 長押しで入れ替え・削除。 差し替えるときは「全期間」か「指定した日以降だけ」を選べて、それまでの出席記録は書き換わりません。
  • 友達の時間割は横スワイプで切り替え。時限の時刻が自分と違う友達には印がつきます。友達のコマを、自分の未配置の授業にコピーできます。
  • 「今日の友達の時間割」で、友達と自分を列・時限を行にした一覧が見られます。
  • 時間割を1枚の画像にして共有できます。この画像だけに効く背景・濃さ・テーマカラー・書体・ライト／ダークを設定できます（アプリ本体の見た目は変わりません）。
  • みんなの授業：友達が公開した授業を検索・絞り込みして、自分の時間割にコピーできます。

授業

  • 授業名・教室・教員（複数）・メモ（非公開）・単位数・区分・取得済みフラグを入れられます。
  • 複数の曜日・時限に置けます。学期をまたぐ開講にも対応（同じ科目は束ねて扱い、二重に表示しません）。
  • 色は個別に決めるほか、単位区分の色に合わせることもできます。
  • 出席率と出席履歴：出席 / 遅刻・早退 / 欠席 / 休講 / 未記録で絞り込めます。「全部出席にする」、時間割外の補講の手動追加、回の削除もできます。
  • その授業の課題一覧・試験一覧へ移動できます。

📝 出欠でできること記録できるのは 出席 / 遅刻・早退 / 欠席 / 休講 の4つです。ここから出席率が自動で計算され、それぞれの回数も一覧で見られます。

課題

  • 未提出（締切順）→ 提出済み の順に並びます。チェックで完了。ホームからもクイック完了できます。
  • 授業との紐付け、期限なし / 日付のみ / 日時指定、メモ、提出先のURL。
  • 状態は 未着手 / 進行中 / 提出準備済み / 提出済み の4段階。提出日も残ります。
  • リマインダーはいくつでも付けられます。

試験

  • これから / 終了した の一覧。授業との紐付け、試験名・日時・教室・メモ。
  • 時限の開始時刻から時刻を選べるボタンがあります。
  • ホームとカレンダーにもまとめて表示されます。

単位（卒業条件） 設定でONにする

設定で有効にすると使えます。卒業に必要な総単位と、単位区分（必修・選択など）ごとの目標単位を、ミッション形式で管理します。

  • 必修の授業は、残っている科目がチェックリストで出ます。
  • 区分の追加・編集・削除、色と並び順、既定の区分、取得済み授業の折りたたみ。
  • 集計は全学期を通算します。
  • プレミアム 単位・授業のCSV書き出し。

くらし（家計簿・バイト・タスク・就活）

上部のボタンで 家計簿 / バイト / タスク / 就活 を切り替えます。どれも他人には1行も渡りません。

家計簿 設定でONにする

はじめは出していません。設定でONにすると、いちばん左に出てきます。

  • 月ごとの収入・支出・収支。横スワイプや月ラベルのタップで月を移動。年間の収支も出ます。
  • 毎日の収支が出る簡易カレンダー。日をタップするとその日の明細が見られます。
  • 入れるのは 日付 / なにに使った（もらった）/ 金額 の3つと、収入・支出の区別だけ。カテゴリ分類は持っていません（続けられることを優先しています）。
  • バイト代は行を保存せず、シフトから毎回計算します。 終わったシフトだけを実績に数え、まだ先のシフトは「予定」として合計の外に出します。設定でON/OFFでき、タップするとバイト側に飛びます（家計簿側では編集できません）。
  • 割り勘は自分で取り込みます。 提案カードを押すまで家計簿の数字は動きません。「入れない」を選んだ記録も残るので、あとから入れ直せます。取り込んだあとに元の金額が変わったら知らせるだけで、勝手に書き換えません。
  • 欲しいもの：商品名と値段だけのメモ。収支には一切入りません。
  • プレミアム 家計簿のCSV書き出し（バイト代の派生ぶんも含みます）。

⚠️ 家計簿は共有されません家計簿と「欲しいもの」は、友達にも1行も渡りません。割り勘（＝共有されます）と金額をやりとりしますが、家計簿側の数字が相手に届くことはありません。

バイト

  • 月ごとのシフト管理。予定の給与と実績の給与、勤務時間、月間・年間の実績が出ます。
  • 勤務先ごとに 名前・基本時給・色・深夜/早朝の時間帯と割増率・税率を設定できます。
  • 勤務先を変えるときは「今後のみ」か「すべて」を選べます。削除しても過去のシフトは残り、将来のシフトだけ消えます。
  • 日をまたぐ勤務に対応。毎週・隔週＋曜日指定の繰り返し、「今回・今後・すべて」の編集。
  • 実際に働いた時刻の記録、課税・非課税の追加収入、通常 / 深夜 / 早朝 / 税 / 手取りの内訳表示。
  • まとめて追加：カレンダーで複数の日を選んで、一気にシフトを入れられます。
  • プレミアム 繰り返しを展開したシフトのCSV書き出し。

タスク

  • 未完了（期限順）→ 完了。タイトル・メモ・優先度（なし / 低 / 中 / 高）。
  • 期限なし / 日付のみ / 日時指定。リマインダーはいくつでも。
  • ホームのタスクカードにもまとまって出ます。
  • iOS 「MIO」専用のリマインダーリストができて、双方向で同期します。連携を解除しても、既存のタスクとリマインダーは両方そのまま残ります。

就活

  • 選考中 / 終了した企業。志望度1〜5、企業ごとの色、「次の予定順」「志望度順」の並び替え。
  • 選考ステージは 興味 → 説明会 → インターン → 応募準備 → 書類 → 試験 → 面接 → 内定 → 終了。
  • さらに細かく、企業研究・セミナー・面談・適性検査・GD/GW・面接の回数・終了理由まで残せます。
  • 複数のURL、メモ、企業に紐づく予定（場所・繰り返し・リマインダー）。
  • 予定はホームとカレンダーにもまとめて出ます。

友達と Touch

「友達」タブには イベント / サークル / 割り勘 / 友達 があります。ここにあるものは、いじると相手に届きます。 イベントとサークルの新着は、まとめて1つの赤い印になります。

自分のID・QRコード

「友達」の自分の欄から、フレンドコード（ID）とQRコードを出せます。渡し方は4通り：QRコードを見せる / カメラで読み取る / IDを手で入れる / リンクを送る。テキストでも画像でも共有できます。

📝 メモIDの再発行は30日に1回までです。作り直すと前のQR・IDは使えなくなりますが、すでにつながっている友達はそのままです。

友達を追加する

お互いの承認で成立します。承認するときに「時間割を見せるか」「授業カタログを見せるか」をその場で選びます。 申請は承認・拒否・取り消しができます。上限は500人です。

別名（ニックネーム）・タグ

友達ごとに、自分だけに見える別名とタグを付けられます。相手には渡りません。並び替えにも使えます。

友達ごとの公開設定

友達の詳細画面から、自分の時間割・授業カタログ・Touch をその相手にどこまで見せるかを1人ずつ決められます。ブロックと削除もここから。

  • 削除：もう一度つながるには、ID/QRから追加し直します。
  • ブロック：設定の「ブロック一覧」から解除できます。

Touch / High Touch

友達を長押しすると送れる、軽い挨拶です。

  • 新しく送れるのは1日3回まで、同じ相手には1日1回まで。
  • 2時間以内に返せば、送信の枠を消費しません。
  • お互いに成立すると High Touch。全画面の演出と紙吹雪、通知が入ります。累計回数の節目でも演出があります。
  • 受け取りたくないときは無効にできます。受信の上限も1〜10回/日で設定できます。

イベント（飲み会・旅行の幹事ツール）

一覧は 開催前 / 要回答 / 開催済み / 非表示 に分かれます。

作り方

  1. ジャンルを選ぶ（飲み会・ごはん・カラオケ・旅行・合宿・BBQ・勉強会・デートなど37種）。
  2. 名前を決める。
  3. 日時を決める（終日 / 日時未定 / 繰り返し / 日程調整の候補日）。
  4. 場所（地図・最近の場所から選べます）。
  5. メンバーを選ぶ。友達だけでなく「名前だけ」でも追加できます（MIOを使っていない人も入れられます）。
  6. 幹事と編集権限を決める。

幹事と権限

幹事は複数置けます。追加・解除・譲渡ができ、編集権限は 全面編集 / メンバー追加のみ / 編集不可 から選べます。

出欠

参加 / 不参加 / 未定 / 未回答。繰り返しのイベントなら「今回だけ」「今後」で答えを分けられます。誰が来るか来ないかはひと目でわかります。

日程調整

  1. 候補日を並べて、メンバーが ○ △ × で投票。
  2. いちばん集まれる候補が表示されます。
  3. 幹事が1つに確定します。

📝 メモ日程を変えると回答はリセットされます。そのとき通知するかどうかを選べます。

ほかに、場所・地図・複数のURL・メモ、テキストでの共有、サークルとの紐付け、非表示と再表示ができます。イベントには割り勘を1つ紐づけられます（1イベント＝1回につき1つ）。

サークル

位置づけは「幹事の管理帳」です。お金はアプリの中で動かしません。

作成・メンバー

  • 作れるのは30個まで。名前・説明・活動する曜日と時間帯（月〜日 × 午前/午後/夜間）を設定できます。
  • 招待は優先して表示され、参加 / 辞退を選びます。友達の招待と「名前だけ」のメンバー追加、どちらもできます。
  • 管理者と、複数の役職（独自の役職も作れます）。管理者の昇格・解除、所有権の譲渡、メンバーの追加・削除、脱退・削除。

参加申請リンク

リンクを配って参加申請を受けられます。リンクから来た人は申請として並び、管理者が承認します。

おしらせ（掲示板）

  • 1件100文字まで。URLは自動でリンクになります。連投を防ぐため、投稿には5分の間隔があります。
  • 最大2件を固定できます。自分の投稿と、管理者の権限で削除できます。
  • 無料では最新100件。プレミアム メンバーに1人でも加入者がいれば、サークル全員が500件見られます。 枠を超えたデータも消さずに保持します。

募集・お誘い

タイトル・説明・日時・定員・締切・参加費・場所を決めて募集を出せます。状態は 募集中 / 満員 / 受付終了 / 終了。手を挙げる・取り消すができ、共有イベントに変換することもできます（変換しなくてもよく、手を挙げてもらうだけの使い方もできます）。

見た目

アイコンと16:9のヘッダー画像を設定できます（全メンバーに反映されます）。プレミアム 画像を変えられるのは、自分が加入者で、かつそのサークルの管理者のときだけです。なお色は誰でも変えられます（自分にだけ効きます）。

通知

設定の「通知」でまとめて調整します。プリセットは 多い / ふつう / 少ない / カスタム。種類ごとに個別のON/OFFもできます。

  • 授業：開始5分前
  • 課題：締切の指定日数前、9:00

  • 就活：説明会・面接などの予定前

文面は日替わりで変わるので、毎日同じ文章にはなりません。OSに予約されている通知の一覧も画面で確認できます。

💡 通知が来ないときまず設定「通知」のスイッチを確認し、それでも来なければ端末本体の通知設定でMIOが許可されているかを見てください（アプリ内に警告が出て、端末の設定へ移動できます）。

アカウントとデータの引き継ぎ

  • アカウントなしで始められます。 裏で同期用の匿名アカウントが用意されます。
  • Google / Apple でサインインできます。あとから連携を追加でき、匿名から引き継ぐとデータもそのまま移ります。
  • 既存のアカウントに切り替えると、クラウドからデータを取ってきます。別アカウントのローカルデータが混ざらないようガードが入ります。
  • サインアウトすると端末のデータは消え、クラウドには残ります。
  • アカウントとデータの完全削除は2段階の確認つきです。

どのデータが、どこまで届くか

ここがいちばん間違えやすいところです。3つに分かれています。

  • 自分の端末のあいだだけ（他人には1行も渡らない）：授業・単位区分・学期の期間・課題・出欠・試験・バイト先・シフト・タスク・日記・家計簿・欲しいもの・就活の企業・友達リスト
  • 相手に届く：イベントとメンバー・日程の候補と投票、割り勘と明細、サークルとメンバー・おしらせ・募集
  • 端末の中だけ（クラウドに送らない）：iOSリマインダーの紐付け、Touchの集計、申請の控え、通知履歴、画像のキャッシュ、イベントの非表示状態、友達の別名とタグ

💡 引き継ぎは早めに連携していないと機種変更で引き継げません。使い始めたら早めに Google / Apple と連携しておくのがおすすめです。

MIOプレミアム

月額・年額の自動更新サブスクリプションです。無料トライアルがあります。旧「広告削除」の買い切りは販売を終了していますが、持っている人の権利は生きています。

  • バナー広告が非表示になります（無料版は下に1枚。カレンダーには出ません。起動5回目から出ます）。
  • 通知キャラクターが6種に増えます。
  • ホーム画面ウィジェットが21種に増え、1つずつ別の背景を設定できます。

  • サークルの画像変更（管理者権限のあるサークルのみ）。
  • CSV書き出し（バイト・出席・授業/単位・家計簿）。
  • 共有画像に入るアプリのリンクを、時間割・バイトそれぞれで外せます。

⚠️ 購入の決まり1購入＝1アカウントです（ファミリー共有は受け付けていません）。別のアカウントで復元しようとすると、移行の確認が入ります。契約の管理は、購入したストア（App Store / Google Play）で行います。反映されないときは「購入を復元」をお試しください。

保存容量とデータの削除

  • クラウドに預けられる量には枠があります。種別ごとの使用量を画面で確認できます。
  • 枠を超えても、既存のデータは保持されます。 新しく作るのだけが止まります。

📝 削除のしくみ削除は「消したという記録」を残す方式です（そうしないと、同期のときに他の端末から復活してしまいます）。お掃除をしても、端末の表示から消えるだけで実データはすぐには消えません。

よくある質問（Q&A）

アカウントを作らなくても使えますか？

はい。最初の設定で「アカウントなしではじめる」を選べば、そのまま使えます。データは端末内に保存されます。機種変更などで引き継ぎたくなったら、あとから設定でGoogle/Appleと連携できます。

ネットにつながっていなくても使えますか？

使えます。時間割・出欠・課題・予定・バイト・家計簿・日記などは端末内で動きます。友達への共有やクラウドへの反映だけ、電波が戻ったときや次に画面を開いたときに自動で行われます。

機種変更のときのデータの引き継ぎは？

設定の「アカウント」でGoogleまたはAppleと連携しておき、新しい端末で同じアカウントでログインすると復元されます。連携していないと引き継げないので、早めの連携がおすすめです。

家計簿が見つかりません。

家計簿は、はじめは出さないようにしてあります。設定でONにすると「くらし」タブのいちばん左に出てきます。単位管理も同じく、設定でONにすると「学校」タブに出ます。

割り勘はどこにありますか？

「友達」タブの「割り勘」にあります。独立した機能なので、イベントと関係なく単体でも作れますし、イベントに紐づけて作ることもできます（1イベント＝1回につき1つ）。

友達を招待して出欠をとりたいです。

「友達」タブのイベントを使ってください。イベントを作ってメンバーを招待すると、参加/不参加/未定の出欠をとれます。開催日が未定なら「日程調整」で候補日に○△×投票して決められます。MIOを使っていない人も「名前だけ」で追加できます。

時間割に友達が出てきません。

相手が自分に対して時間割を公開していて、かつ、あなたがその友達の時間割を表示する設定になっている必要があります。友達の詳細画面（公開設定）や、友達を承認したときのチェックで切り替えられます。

授業がカレンダーに出ません。

授業をカレンダーに重ねるかどうかは設定で切り替えます。設定で有効にすると、カレンダーに授業も並ぶようになります。

学期を切り替えたら授業が消えました。

「時間割」は選んだ学期のものだけを表示します。上部の学期の見出しをタップして切り替えてください。なお「授業」の一覧のほうは、学期を切り替えても全学期の授業が並びます。

学期の途中で授業（曜日・時限の中身）が変わりました。

時間割のそのコマを長押しして入れ替えると、切り替える境目の日を指定できます。その日から新しい授業、前日まで元の授業として扱われ、それまでの出席は書き換わりません。

出席をつけ忘れました。まとめて出席にできますか？

できます。授業の詳細（出席履歴）で未入力が残っていると「全部出席にする」が使えます。ホームの今日の授業でも「今日ぶんをまとめて出席」が出ます。個別の回はタップで 出席/遅刻・早退/欠席/休講 を選べます。

課題の「進行中」などの状態は何段階ですか？

4段階です。未着手 → 進行中 → 提出準備済み → 提出済み。提出した日も残ります。一覧は未提出が締切順に並ぶので、次にやることで迷いません。

フレンドコード（ID）を作り直したいです。

自分の情報画面から再発行できます。ただし30日に1回までです。作り直すと以前のQR・IDは使えなくなりますが、すでにつながっている友達はそのままです。

友達を削除するとどうなりますか？ ブロックとの違いは？

どちらも相手はあなたの情報を取得できなくなります。違いは元に戻す方法です。削除はもう一度つながるにはID/QRから追加し直し、ブロックは設定の「ブロック一覧」から解除できます。別名やタグは相手には伝わりません。

Touch が送れません。

新しく送れるのは1日3回まで、同じ相手には1日1回までです。ただし相手から届いたTouchに2時間以内に返す場合は、送信の枠を消費しません。相手が受け取りを無効にしている場合も送れません。

通知が来ません。

設定「通知」で「通知を受け取る」がONか、種類ごとのスイッチがONかを確認してください。それでも来ない場合は、スマホ本体の通知設定でMIOが許可されているかを確認してください（アプリ内に警告が出て、端末の設定へ移動できます）。Androidでは、端末が正確なアラームを許可していないと数分ずれることがあります。

通知の口調（キャラクター）を変えられますか？

はい。設定「通知」の「通知のキャラクター」から選べます。無料は システム / 女の子 / 男の子 の3種で、MIOプレミアムに入ると ツンデレ / 余裕のある大人の男性 / トーク風 が増えて計6種になります。内容は同じで、言い回しだけ変わります。

ウィジェットが置けません。

Androidは、アプリ内のウィジェットギャラリーからタップして配置を要求できます。iPhoneはOSの仕様で自動配置ができないので、ホーム画面を長押し →「＋」→ MIO の手順で置いてください。アプリ内にも手順の案内があります。

広告を消せますか？ 機種変更したら購入し直し？

MIOプレミアムに加入すると広告が非表示になります。購入権はMIOアカウントに紐づくため、同じMIOアカウントなら再購入は不要で、iOSとAndroidの両方で利用できます。新しい端末で反映されない場合は「購入を復元」をお試しください。

背景を自分の写真にできますか？ 友達に見えますか？

できます。設定「デザイン」の背景で、自分の写真を選んで切り抜けます。背景は自分にだけ表示され、友達には共有されません。濃さも調整できます。

プリセット（かわいい・ゆめかわ等）をあとから選び直したいです。

プリセットを一覧から選ぶ画面は、はじめて開いたとき（初期設定）にだけ出ます。あとからは、設定「デザイン」でテーマカラー・背景・書体・カードの濃さを1つずつ変えてください。ライトとダークで別々に設定できます。

データを全部消したいです。

設定のいちばん下「すべてのデータを削除」から実行できます。ただしこのアカウントは二度と使えなくなり、元に戻せません。引き継ぎたい場合は先にアカウント連携を。実行前に確認ダイアログが出ます。

解決しないときは、アプリの設定 →「お問い合わせ」から、種別・内容・返信先メール（と必要ならスクリーンショット）を添えてお送りください。アプリ内には、もっと細かい項目まで引けるよくある質問も入っています。
